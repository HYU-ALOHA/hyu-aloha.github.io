# 강의자료 PDF 관리

강의자료 카드의 다운로드 파일은 이 폴더에서 관리합니다. 페이지에 표시할 링크와 설명은 `app/lecture-pdf/lecture-data.ts`에서 수정합니다.

파일명은 `week-{주차}-{카드 번호}.pdf` 형식을 사용합니다.

예시:

- `week-1-1.pdf`
- `week-1-2.pdf`
- `week-2-1.pdf`

같은 이름의 파일을 교체하면 웹사이트 코드를 수정하지 않아도 다운로드 자료가 갱신됩니다.

각 주차의 `materials`는 초급반, 중급반, 고급반 순서이며 각 항목에 아래 값을 입력합니다.

- `pdfUrl`: 다운로드할 PDF 주소
- `description`: PDF 카드 아래에 표시할 설명
